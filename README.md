### 1. Problema de negócio

Previsão de vendas em Projeto Rossmann com dados disponibilizado no Kaggle com editor de código VS Code em linguagem Python com as bibliotecas Pandas, NumPy, Scikit-Learn, XGBoost, Seaborn, Matplotlib, BorutaPy. Aplicadas na padronização e limpeza de dados; estatística exploratória descritiva e validação de hipóteses; seleção de variáveis relevantes para modelos de Machine Learning; definição de conjunto de valores de hiperparâmetros; interpretação de erros e deploy do modelo em produção.
Recebe dados em JSON e retorna a predição de vendas.
